# 芳沈手册（语法糖手册）

一款面向精神医学用药自我管理的原生 Android 应用：记录服药剂量，把每种药的血药浓度与效应变化绘制成示意图，并在联合用药时给出相互作用与负荷预警。

> 本软件为科普辅助工具，所有浓度曲线与效应推演均为**示意性估算**，不构成任何医疗建议。用药请遵医嘱。

## 功能一览

- **服药记录**：按药库点选服药（单片剂量自动带出），也可手动输入任意剂量；自定义药物与剂量随手补录。
- **血药浓度示意图**：以 Bateman 吸收-消除模型逐点绘制当前各药的浓度曲线（主页，横轴以 12 小时为单位），点按图表可切换 毫克 / 克 / 微克 单位。
- **效应引擎**：把剂量规则映射为 30 余种主观/客观效应（镇静、欣快、镇痛……），含反向抵消（如兴奋抵消镇静）与权重合并，形成当前效应面板。
- **联用预警**：
  - **酶学层**：CYP 等代谢酶的抑制/诱导/竞争，按分子标签推断浓度变化方向；
  - **药效学层**：机制配对（MAOI × 5-HT 能 → 5-HT 综合征；阿片 × GABA → 协同性呼吸抑制；NSAID × 锂盐 → 锂蓄积 等）双向检查；
  - **负荷层**：血清素能 ≥2、抗胆碱能 ≥2、中枢抑制 ≥3 时提示叠加负荷。
- **自定义《预警》**：按“药品组合 / 个人画像（11 类 DSM-5 障碍、73 项条目）→ 附加效应权重”配置规则，可逐侧开关“按药物 / 按标签”匹配。
- **处方模块**：JSON 处方文件记录药物组合与适应症，进入编辑页即实时估算联用效应与相互作用，并支持长按截图分享。
- **药库**：内置 202 种有精神效应的物质（含 9 种激素/内分泌药），覆盖 SSRI/SNRI、三环/四环、MAOI、三代抗精神病药、心境稳定剂、苯二氮卓类、兴奋剂、镇痛药（NSAIDs、阿片类、奈福泮）、胆碱酯酶抑制剂、保健品与食品、尼古丁/乙醇/槟榔碱/咖啡因；
- **抗组胺/抗胆碱能谵妄剂**（苯海拉明、茶苯海明、多西拉敏、东莨菪碱）、**加巴喷丁类**（普瑞巴林、加巴喷丁）、**NMDA 类**（金刚烷胺、美金刚、地佐环平）、**拉西坦类益智药**（吡拉西坦、阿尼西坦、奥拉西坦、左乙拉西坦、芬洛西坦）以及**常见精神活性物质**（甲基苯丙胺、苯丙胺、MDMA、可卡因、甲卡西酮、恰特草、海洛因、大麻、裸盖菇素、麦司卡林、DMT、一氧化二氮、苯环利定、GHB、亚硝酸异戊酯、甲喹酮及多种催眠镇静类）、**镇吐药**（多潘立酮、甲氧氯普胺、昂丹司琼、格拉司琼、阿瑞匹坦）、**逆转剂**（纳洛酮、氟马西尼、赛庚啶、肾上腺素、毒扁豆碱、阿托品、艾司氯胺酮）与**促认知补剂**（胞磷胆碱钠、磷脂酰丝氨酸）——用于风险自知与减害记录。
- **非线性药代与活性代谢物**：乙醇/苯妥英的容量限制消除、卡马西平自诱导、加巴喷丁吸收饱和（RK4 数值积分）；氟西汀、地西泮、曲马多、海洛因、可待因、利培酮的活性代谢物链
- **手册**：左抽屉内置效应词典（效应定义、效应包与通俗描述），自定义效应/效应包可在手册页直接增删改
- **代谢物曲线与高亮**：点按药物卡片高亮其母药与代谢物曲线（其余淡出）；去甲氟西汀等活性代谢物以延迟生成模型独立绘制
- **成瘾游标线**：按药物声明的小时速度恒速游向当前浓度（不越界），交叉耐药组共享一条线；剂量低于游标 50% 时戒断权重加重，可在「设置」开启常显
- **效应急慢性**：规则级急性/慢性标记（如 SSRI 的「愉悦」为慢性、丁螺环酮的「镇静」为慢性），同名急慢双触发时合并权重并只显示急性
- **多给药途径**：短按 = 默认途径 + 标准单位；长按 = 自定义剂量、单位与途径（从声明的途径中选）
- **报告系统**：场景片段（时间/地点/描述）+ QQ 式对话片段（发言人、对话、事件），正文内联 Markdown 子集（粗体/斜体/删除线/代码）
- **文档系统**：六类（药代/药效/药物化学/精神病理/认知行为疗法/精神分析学，37 篇内置 + 用户自建）的通俗读物，支持目录锚点与跨文档跳转
- **统计页**：服药记录总数、累计种类数；按日期回看当日服药与当日报告（报告仅出现在统计页）
- **精麻标识**：麻醉/精神药品在服药卡片药名后标注图标（「设置」默认关闭）
- **药库扩充（v4）**：丙泊酚、食欲素受体拮抗剂（苏沃雷生/莱博雷生/达利雷生）、策划药（MDPV、α-PVP、2C-B、25I-NBOMe、5/6-APB 等）、笑气与 Poppers 的成瘾参数

## v5 更新

- **文档库扩容与自建**：新增内置分类「认知行为疗法」，六类共 37 篇通俗读物（药代/药效/药物化学/精神病理/认知行为疗法/精神分析学）；支持新建自建分类与自建文档（本地持久化），文档页右上角相机按钮可把整页截图保存到相册「Pictures/芳沈手册」
- **药物画像数据**：全部 193 种内置药补齐简介与展示属性（如「镇静 2–4」「血栓风险」），详情页内以两点区间条展示；纯展示，不影响效应与药代推演
- **详情页联用预警**：与近 7 天在服药物存在机制冲突时，详情页顶部以黄色卡片列出（酶学机制 + 建议）
- **内置联用预警一览**：「预警」页以圆角卡片列出 20+ 条内置机制预警（5-HT 综合征、协同呼吸抑制、锂蓄积等）
- **激素与内分泌药**：雌二醇、戊酸雌二醇、螺内酯、胰岛素、环丙孕酮、左甲状腺素、泼尼松、地塞米松、睾酮（替代治疗与内分泌调节记录，不纳入成瘾引擎）
- **个人画像条件**：身体数据（性别/体重/身高/BMI）入画像；自定义预警可按性别、体重区间附加条件；精神障碍细分至 11 类（解离、睡眠-觉醒、神经发育等按 DSM-5 维度进一步拆分）
- **效应程度三档**：「设置」中 6 类效应包均可分别设置 轻/中/重 显示档位
- **图表阅读辅助**：当前/12h/24h 三条竖线等分时间轴；小时/分钟单位修正
- **自定义活性代谢物**：自定义药物可挂活性代谢物（内置键或 custom:id），浓度曲线同步绘制
- **交互与细节**：服药条目上下外边距改 0dp、报告入口移回左抽屉、处方图标更换、精麻标识可在设置中一键隐藏

## 技术栈

- Kotlin + Jetpack Compose，Material 3，浅色竖屏手机形态
- 图表：[Vico](https://github.com/patrykandpatrick/vico) 2.x
- 剂量以 `BigDecimal` 存储与运算，避免浮点误差
- 数据为设备本地 JSON（应用专有目录），无云端、无账号

## 目录结构

```
app/src/main/java/com/fangshen/manual/
├── model/          DrugCatalog(202 种内置药，按 5 个分片对象拆分避免 <clinit> 超限)、Effect、Prescription、TagColors…
├── engine/         PkEngine(药代动力学)、EffectEngine(效应)、InteractionEngine(联用预警)、AlertRules
├── ui/home/        主页(浓度曲线+效应面板)、服药抽屉、左右抽屉
├── ui/prescription/处方列表/编辑/分析
├── ui/dose/        服药明细录入
└── ui/theme/       Material 3 主题
```

## 构建与安装

需要 JDK 17、Android SDK（compileSdk 35）、Gradle 8.10.2：

```bash
git clone git@github.com:inline-function/Function-Manual.git
cd Function-Manual
gradle --no-daemon assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

发布包使用 `app/fangshen.jks` 签名（密钥不随仓库分发，请自备 signingConfigs）。

## 数据位置

- 服药记录、自定义药物、预警规则：`<应用专有目录>/files/fangshen/data.json`
- 处方：`<应用专有目录>/files/fangshen/prescriptions/*.json`
- 报告：`<应用专有目录>/files/fangshen/reports/*.rp`
- 文档种子：`app/src/main/assets/docs/docs.json`
