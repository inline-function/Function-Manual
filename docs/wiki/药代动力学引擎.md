# 药代动力学引擎（PkEngine）
位置：`engine/PkEngine.kt`。主页浓度曲线由它逐点算出。
## 模型
单室 Bateman 方程（血管外给药先吸收后消除）：
```
C(t) = D · F · ka / (V · (ka − ke)) · (e^(−ke·t) − e^(−ka·t))
```
- `V = 50 L` 固定表观分布容积；
- `ke = ln2 / t½`，半衰期裁剪在 0.25h ~ 720h；
- `ka = ln2 / tmax + ke`（由达峰时间反推，使峰值落在 tmax 附近）；
- 静注/肌注视为瞬时吸收，`ka = 20`；
- `F` 为口服生物利用度（0–100%）；
- 多次给药按线性叠加求和。
默认 tmax 按给药途径：静注 0.05h、肌注 0.5h、鼻腔 0.75h、舌下 1.0h、口服 2.0h、直肠 1.5h。

## 非线性药代（v3）
声明了非线性消除的药物改用 RK4 数值积分（吸收室→中央室两条 ODE，步长 0.1h），线性药保持闭式解：

- **容量限制消除（Michaelis–Menten）**：dC/dt = −Vmax·C/(Km+C)。乙醇（Vd 35L、Vmax 200mg/L/h、Km 30mg/L）社交剂量下近似零级消除——曲线直线下降而非指数衰减；苯妥英（Vmax 0.41mg/L/h、Km 4mg/L）剂量小幅增加即可使浓度不成比例跃升。
- **自诱导**：ke_effective(t) = ke·(1+λ·(1−e^(−t/τ)))。卡马西平 τ=7 天、1+λ=2.3（t½ 35h→15h），连续服用数周后同一剂量浓度显著降低。
- **吸收饱和**：F(D) = fMax·d50/(d50+D)。加巴喷丁 d50=390mg，300mg 时 F≈57%、1600mg 时 F≈20%——高剂量递增收益递减。
- 剂量内部统一换算为 mg，输出再换算回药物单位，浓度刻度与线性路径一致；未声明的旧药不受影响。

## 活性代谢物（v3）
母药可声明 activeMetabolites 引用库内另一条目（通常为隐藏条目）。母药每次服药会生成一条该代谢物的"伪服药"：

- 等效剂量 = 母药剂量 × fm × 效价，时间后移约母药 t½（形成延迟）；
- 代谢物自身的 t½ 与效应规则生效：去甲氟西汀（t½ 9 天）解释了氟西汀停药后的长尾；去甲西泮（t½ 100h）解释了地西泮连用蓄积；
- 已实现链：氟西汀→去甲氟西汀、地西泮→去甲西泮、曲马多→去甲曲马多、海洛因→吗啡、可待因→吗啡（fm 10%）、利培酮→帕利哌酮；
- 伪剂量只在内存中推算，不写盘、不进入台账时间线。

## 示意性声明
非线性参数取自经典药理学教材的群体均值；不含蛋白结合率与重复给药稳态的严格处理，置信度低，仅用于形成直觉。
