# 构建与运行

- JDK 17 + Android SDK（compileSdk 35，minSdk 见 app/build.gradle.kts）
- Gradle 8.10.2、Kotlin Compose 插件、KSP
- Vico 图表库来自 Maven Central

```bash
gradle --no-daemon assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

签名：`signingConfigs.release` 使用 `app/fangshen.jks`（alias fangshen）。密钥不入库，需自行生成：

```bash
keytool -genkeypair -keystore fangshen.jks -keyalg RSA -validity 20000
```

不签名只想调试时用 `assembleDebug`。
