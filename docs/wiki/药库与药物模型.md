# 药库与药物模型（DrugCatalog）

位置：`model/DrugCatalog.kt`、`model/Drug.kt`。

## 内置 184 种（181 可见 + 3 条隐藏活性代谢物）

- **抗抑郁**：SSRI（氟西汀、西酞普兰、艾司西酞普兰、氟伏沙明、帕罗西汀、舍曲林）、SNRI（度洛西汀、文拉法辛）、米氮平、安非他酮、曲唑酮、沃替西汀、噻奈普汀、瑞波西汀、米那普仑；
- **三环/四环**：阿米替林、丙咪嗪、氯米帕明、多塞平、去甲替林；马普替林、米安色林；
- **MAOI**：苯乙肼、反苯环丙胺、吗氯贝胺、司来吉兰；
- **抗精神病**：一代（氯丙嗪、氟哌啶醇等）、二代（氯氮平、利培酮、奥氮平、喹硫平、齐拉西酮、帕利哌酮、阿塞那平、鲁拉西酮、氨磺必利）、三代（阿立哌唑、依匹哌唑、卡利拉嗪）；
- **心境稳定**：锂盐、丙戊酸、卡马西平、拉莫西平、奥卡西平；
- **镇静/抗焦虑**：苯二氮卓类、Z 类、丁螺环酮、坦度螺酮、苯巴比妥；
- **兴奋剂**：哌甲酯、阿托莫西汀、莫达非尼；
- **镇痛**：对乙酰氨基酚、NSAIDs、奈福泮、阿片类（吗啡、芬太尼贴剂、羟考酮、美沙酮、丁丙诺啡舌下、哌替啶、喷他佐辛、他喷他多、曲马多、可待因、氢可酮、右美沙芬）；
- **认知增强**：多奈哌齐、加兰他敏（梦境增强剂）、利斯的明、石杉碱甲（记忆增强剂）、胞磷胆碱钠、磷脂酰丝氨酸；
- **拉西坦类益智药**：吡拉西坦、阿尼西坦、奥拉西坦、左乙拉西坦、芬洛西坦；
- **抗焦虑加巴喷丁类**：普瑞巴林、加巴喷丁（α2δ 钙通道配体，参与阿片协同呼吸抑制的配对检查）；
- **NMDA 解离剂**：金刚烷胺、美金刚、地佐环平（与氯胺酮同列"解离剂"组）；
- **抗组胺/抗胆碱能谵妄剂**：苯海拉明、茶苯海明、多西拉敏、东莨菪碱（触发抗胆碱能负荷计数）；
- **镇吐药**：多潘立酮、甲氧氯普胺、昂丹司琼、格拉司琼、阿瑞匹坦（效应引擎中以"镇吐"抵消恶心）；
- **逆转剂**：纳洛酮（逆转阿片）、氟马西尼（逆转苯二氮卓）、赛庚啶（血清素综合征）、肾上腺素（过敏性休克）、毒扁豆碱（逆转抗胆碱能谵妄）、阿托品（有机磷中毒，大剂量亦为谵妄剂）、艾司氯胺酮（鼻喷速效抗抑郁）；
- **抗癫痫药**：苯妥英（Michaelis–Menten 非线性消除的示范）；
- **抗感染药**：头孢哌酮、甲硝唑、克拉霉素、红霉素、环丙沙星、利福平、利奈唑胺、异烟肼、酮康唑——参与联用预警（双硫仑样反应、CYP 酶抑制/诱导、单胺氧化酶抑制）；
- **心血管药**：普萘洛尔、美托洛尔、比索洛尔、可乐定、甲基多巴、利血平、氢氯噻嗪、吲达帕胺、硝苯地平、氨氯地平、依那普利、氯沙坦——带来嗜睡/头晕/抑郁等精神相关副作用，噻嗪类利尿剂并入锂盐蓄积配对；
- **隐藏条目**：去甲氟西汀、去甲西泮、去甲曲马多（活性代谢物，不在药库展示，由母药自动推算）；
- **常见精神活性物质（含受管制毒品）**：甲基苯丙胺、苯丙胺、MDMA、可卡因、甲卡西酮、恰特草、海洛因、洛哌丁胺、大麻、裸盖菇素、麦司卡林、DMT、一氧化二氮、苯环利定、GHB、亚硝酸异戊酯、氟硝西泮、三唑仑、咪达唑仑、硝西泮、甲喹酮；
- **保健品与食品**：褪黑素、甘氨酸镁、苏糖酸镁、孕烯醇酮、5-HTP、色氨酸、圣约翰草、缬草、卡瓦、银杏、人参、鱼油、肌醇、茶氨酸；
- **其它嗜好物**：尼古丁、乙醇、槟榔碱、咖啡因。

## 药物模型字段

- `halfLifeHours`、`tmaxHours`、`bioavailabilityPct`：PkEngine 参数；
- `tabletDose` + `doseUnit`(MG/G/MCG)：单片剂量，服药与处方点选时自动带出；
- `subjectiveTags`：主观标签，用于列表分组与配色（如“抗抑郁剂”“心境稳定剂”）；
- `effectTags`：机制/分子标签（如“选择性血清素再摄取抑制剂”），供联用预警与规则匹配；
- `rules`：剂量→效应规则列表；
- `managementClass`：管制级别（如 CONTROLLED_I）。
