# 自定义《预警》规则（AlertRule）

位置：`model/Alert.kt`、`ui/alert/AlertScreen.kt`。规则存在 data.json。

## 数据结构

```kotlin
data class AlertRule(
    val id: Long,
    val name: String,          // 规则名
    val enabled: Boolean,
    val drug: String,          // 主药物匹配串
    val withDrug: String?,     // 联用药物匹配串（画像规则为 null）
    val withProfile: String?,  // 画像匹配（联用规则为 null）
    val effect: String,        // 触发后加权重的效应名
    val weight: Int,
)
```

## 匹配串

`drug` / `withDrug` 可以填三选一：

- 药物名（如“吗啡”）；
- 效应/机制标签（如“苯二氮卓类受体激动剂”）；
- 主观标签（如“镇痛剂”）。

匹配逻辑：`name == value || value in subjectiveTags || value in effectTags`。

## 画像条件

`withProfile` 可以填 11 类 DSM-5 障碍类别名（如“情感障碍”）或 73 项具体条目名（如“双相I型障碍”）。
个人画像里勾选的类别与条目构成 `profileFlags`，命中即触发。

## 触发口吻

规则在 `EffectEngine.compute` 第 3 步并入：主药物必须处于生效状态（有效剂量 > 0），且**联用药物或画像**条件成立。触发时以来源“预警·规则名”加入权重。

示例（设备演示）：吗啡 × 阿普唑仑 → 呼吸抑制 +1。
