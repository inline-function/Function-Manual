# 数据格式与位置

全部数据存在应用专有目录（`/Android/data/com.fangshen.manual/files/fangshen/`）， JSON 纯文本，无云端同步。

## data.json

```json
{
  "doses":  [ { "drugKey": "...", "amount": "50", "time": 1736000000000 } ],
  "customDrugs": [ ... ],
  "alertRules": [ { "id": 1, "drug": "吗啡", "withDrug": "阿普唑仑", "effect": "呼吸抑制", "weight": 1 } ],
  "profile": { "disorders": [ "情感障碍", "双相I型障碍" ] }
}
```

剂量用字符串存 BigDecimal，避免 double 精度损失。

## prescriptions/*.json

```json
{ "name": "我的", "drugs": [ { "name": "氟伏沙明", "dose": "50 毫克" } ], "indications": [ "抑郁" ] }
```

处方卡片长按可截图分享（MediaScanner 刷新相册），导出为 `.rp` JSON 文件供其他平台读取。

## 报告（.rp）

报告模块把记录整理为 JSON 报告文件，可在应用内阅读、编辑、分享。
