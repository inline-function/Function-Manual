# 联用预警（InteractionEngine）

位置：`engine/InteractionEngine.kt`。与效应引擎并行，输出结构化警示语。

## 三层机制

### 1. 酶学层

按药物的效应/分子标签推断 CYP 酶上的抑制、诱导、竞争代谢酶关系，给出浓度变化方向（用箭头表示）。

### 2. 药效学配对（MECHANISM_PAIRS）

六对机制，双向检查（forward + reverse）：

| 配对 | 提示 |
| --- | --- |
| MAOI × 血清素能 | 5-HT 综合征 |
| 阿片类 × GABA 能 | 协同性呼吸抑制 |
| 兴奋剂 × MAOI | 高血压危象 |
| NSAID/利尿剂 × 锂盐 | 锂蓄积（v3：噻嗪类利尿剂并入） |
| 双硫仑样药 × 乙醇 | 双硫仑样反应（v3） |
| 血清素能镇痛药 × SSRI 类 | 5-HT 升高/癫痫风险 |
| 乙醇 × 对乙酰氨基酚 | 肝损伤 |

### 3. 负荷叠加（BURDEN_RULES）

- 血清素能药物 ≥ 2 → 血清素负荷；
- 抗胆碱能药物 ≥ 2 → 抗胆碱能负荷；
- 中枢抑制药（GABA + 阿片 + 乙醇/镇静剂）≥ 3 → 中枢抑制叠加。
