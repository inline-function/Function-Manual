# 效应引擎（EffectEngine）

位置：`engine/EffectEngine.kt`，输入“当前各药的有效剂量”，输出效应权重面板。

## 1. 剂量折扣（按半衰期）

对每种药分别计算“生效剂量”：

| 距离现在 | 计法 |
| --- | --- |
| ≤ 1 个半衰期 | 该窗口内剂量**求和** |
| 1 ~ 5 个半衰期 | 取该窗口内**最大单次**剂量 |
| > 5 个半衰期 | 不再计入 |

若某药半衰期内求和为 0，则退回 1~5 半衰期窗口的最大值。

## 2. 剂量→效应规则

每条规则形如“剂量**严格大于**阈值 → 给效应 X 加权重 W”。同一效应被多条规则命中时权重相加。

## 3. 预警规则

见 [[自定义预警规则]]：主药物命中且联用药物/画像命中时，给指定效应加权重。

## 4. 画像规则（占位）

舍曲林生效 + 年龄 ≤ 24 岁 → “自杀冲动” +1。

## 5. 反向抵消

互反效应（如“镇静/兴奋”）两两相消：取两者较小权重 m，各减 m。只有双方权重均 >0 时才抵消。

## 6. 效应包

效应包（如“血清素综合征”）是效应集合。触发包后，其成员效应不单独展示，统一归入包内绘制。

## 展示口径

主页、录药页（DoseRecordScreen）、处方分析都调用 `EffectEngine.compute`；权重 >0 的效应组才渲染。
